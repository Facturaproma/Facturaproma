👥 Membres de l'équipe

Les membres invités peuvent accéder à votre compte selon leurs permissions.

Vous êtes seul pour le moment. Cliquez sur "Inviter un membre" pour ajouter votre équipe.

💡 Comment ça fonctionne ?

  1. Cliquez sur "+ Inviter un membre"
  2. Entrez l'email + choisissez les permissions
  3. Un code d'invitation est généré
  4. Communiquez ce code à votre collaborateur (WhatsApp, email)
  5. Il s'inscrit sur FacturaPro avec ce code
  6. ✅ Il accède à vos données avec les permissions définies
